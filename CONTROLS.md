# Controls

Keyboard and Xbox-style controller bindings remain active together. Select a binding in Settings and press a replacement keyboard key or controller button; rebinding one input family preserves the other. Escape cancels a pending rebind.

| Action | Keyboard | Controller |
|---|---|---|
| Move | Left/Right arrows | Left stick or D-pad |
| Jump / confirm | Space / Enter | South face button (A/Cross) |
| Melee | Z | West face button (X/Square) |
| Shoot | X | Right trigger (RT/R2) |
| Slide / dash | C | East face button (B/Circle) |
| Interact | E | North face button (Y/Triangle) |
| Aim phase marker | Mouse | Right stick |
| Throw / phase to marker | V | Right bumper |
| Recall / cancel marker | Q | Left bumper |
| Open map | M | Back/View/Share button |
| Open inventory | I | Right-stick click |
| Skip cutscene | F | Left-stick click |
| Dialogue backlog | B | D-pad Up |
| Pause / back | Escape | Menu/Start/Options |

Movement supports coyote time, jump buffering, variable jump height, air control, wall slide/jump, and directional dash. Each starting family has distinct attacks and an energy technique. Hold V/right bumper to aim, release to throw the phase marker, press again to teleport, or use Q/left bumper to recall it. Tap-to-aim is available in Settings.

Settings also provide independent movement deadzone, phase-aim deadzone and response, aim assist, vibration, teleport feedback, and hold/tap controls. All twenty-one configurable actions retain keyboard and controller-family bindings where applicable. Reconnects use Godot's active controller discovery and do not invalidate keyboard control.
