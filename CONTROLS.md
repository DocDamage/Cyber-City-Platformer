# Controls

Keyboard and Xbox-style controller bindings remain active together. Select a binding in Settings and press a replacement keyboard key or controller button; rebinding one input family preserves the other. Escape cancels a pending rebind.

| Action | Keyboard | Controller |
|---|---|---|
| Move | Left/Right arrows | Left stick or D-pad |
| Jump / confirm | Space / Enter | South face button (A/Cross) |
| Melee | Z | South face button (A/Cross) |
| Shoot | X | West face button (X/Square) |
| Slide / dash | C | East face button (B/Circle) |
| Interact | E | North face button (Y/Triangle) |
| Pause / back | Escape | Menu/Start |

Movement supports coyote time, jump buffering, variable jump height, air control, wall slide/jump, and directional dash. Melee attacks use a three-step combo; shooting and dashing consume energy that recharges over time.

Settings also provide controller deadzone and vibration controls. Reconnects use Godot's active controller discovery and do not invalidate keyboard control.
