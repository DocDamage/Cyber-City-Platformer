# Music

`Library` contains 54 canonical OGG tracks. The original OGG files were copied directly; only the three tracks that existed solely as MP3 were converted:

- `Rooftops/Cyberpunk Rooftops.ogg`
- `Robot Factory/Mega Robot Factory – 1 .ogg`
- `Robot Factory/Mega Robot Factory – 2 .ogg`

Stage scenes reference only OGG music. Code can resolve a relative library path with `AssetRegistry.get_music_stream()`.
